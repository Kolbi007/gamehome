# 0001: Beslutninger skrives som ADR-er

Dato: 2026-11-01. Status: vedtatt.

## Kontekst

Planen ble utarbeidet i et delt dokument og flyttet hit som `docs/architecture.md`.
Videre endringer trenger et sted der begrunnelsen blir stående.

## Beslutning

Hver arkitekturbeslutning får en kort ADR i `docs/adr/`, nummerert fortløpende: kontekst, beslutning, konsekvenser.
`docs/architecture.md` oppdateres når en ADR endrer noe den beskriver. Oppgaver og bugs går som GitHub-issues.

## Konsekvenser

Copilot og Claude Code kan lese begrunnelsen i repoet. ADR-er endres ikke i etterkant; de erstattes av nye.
