## Funn

- **WinUI leverer ikke kontrollertaster selv** (Windows App SDK 2.5.1): ingen `Gamepad*`-taster kom gjennom XAML.
  All navigasjon gikk via Windows.Gaming.Input. Vi trenger derfor vår egen kontroller-adapter, slik testflaten
  allerede har.
- Kaldstarten er over målet. Neste steg er å måle Native AOT-varianten med samme tester.

### HID-funn (egne målinger, hypoteser til de er bekreftet med en egen test)

Lenovos grensesnitt MI_02 sender rapporter på 64 byte med prefiks `04 00 A1 64`, ca. 5 per sekund selv i ro.
Byte 27–30 endrer seg hele tiden (trolig bevegelsessensor).

- Byte 16 = `0x80` rett før Legion Space tok fokus: trolig **venstre Legion-knapp**. Samme byte hadde `0x01` og
  `0x04` samtidig med D-pad høyre og ned.
- Byte 18 = `0x08` hver gang M2 ble trykket.
- Korte rapporter som `04 00 04 0F`, `04 00 04 12` og `04 00 0F 03` kom når Legion Space åpnet eller lukket seg.

Loggingen var begrenset til 5 rapporter per sekund, så slipp av knappen ble ikke alltid med. Neste probe logger bare
endringer i knappebytene (16–19), uten begrensning.

### Konsekvens

M2 virker som hurtigknapp for øktmenyen nå. Venstre Legion-knapp kan leses, men vi kan ikke stoppe Legion Space fra å
reagere på den. Den kan bli hurtigknapp hvis Legion Space erstattes (for eksempel av Handheld Companion) eller ikke
lenger reagerer på knappen.
