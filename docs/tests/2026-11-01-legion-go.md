# Testrunde 2026-11-01: Legion Go, testflate 0.1.8.0 (JIT)

**Enhet:** Lenovo Legion Go (Gen 1), Windows 11 Home 25H2, build 26200.9711. Kun innebygde kontroller.
**Bygg:** `GameHome.App_0.1.8.0_x64.msix`, JIT med ReadyToRun, selvforsynt.

## Installasjon

- **Sideloading:** testsertifikatet ble lagt i `LocalMachine\TrustedPeople` med `Install-DevBuild.ps1`.
- **Over SSH:** `Add-AppxPackage` feiler med `0x80070005`. Pakken installeres derfor med ett trykk fra skrivebordet.
- **Oppgradering:** 0.1.0.0 → 0.1.8.0 med App Installer virket uten å avinstallere først.

## Funn

- **WinUI leverer ikke kontrollertaster selv** (Windows App SDK 2.5.1): ingen `Gamepad*`-taster kom gjennom XAML.
  All navigasjon gikk via Windows.Gaming.Input. Vi trenger derfor vår egen kontroller-adapter, slik testflaten
  allerede har.
- Kaldstarten er over målet. Neste steg er å måle Native AOT-varianten med samme tester.
