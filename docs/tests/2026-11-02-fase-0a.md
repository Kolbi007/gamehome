# Fase 0A, runde 1 (2026-11-02): GameHome som home app (0.1.19.0, AOT)

Legion Go, Windows 11 25H2 (26200), utviklermodus på.

| # | Test | Resultat |
| --- | --- | --- |
| 1 | Installasjon med `gamingHome`-capability | OK etter retting. 0.1.18.0 feilet med 0x8007007A («failed to register the windows.capability extension») fordi Windows ikke kunne lese SCCD-filen (hendelse 9521 peker på `CustomCapability.SCCD`). Filen hadde en XML-kommentar med æøå; uten kommentaren virker den. |
| 2 | GameHome i listen over home apps | OK, og kan velges |
| 3 | Start Xbox mode | OK. GameHome starter som hjem med vanlig `Launch`-aktivering, 282 ms til første aktivering. |
| 4 | Home i Game Bar under økt | OK. Kommer som protokollaktivering `windows.gaming:///home`, videresendes til kjørende GameHome, som tar forgrunnen og viser «Kjører nå». |
| 5 | M2 etter at økten er avsluttet | Som forventet: ingen øktmeny, tastene kommer som vanlige taster. |

## Funn

- **Home-knappen i Game Bar aktiverer home-appen med `windows.gaming:///home`.** GameHome trenger derfor ikke egen
  kode for å fange Home; single-instance-videresendingen dekker det.
- **Registerverdien `GamingConfiguration\GamingHomeApp` fantes ikke** selv om GameHome var valgt. Hypotesen om hvor
  valget lagres stemmer ikke på denne builden. Logglinjen fjernes eller rettes; GameHome trenger ikke verdien.
- Én gang svarte Windows «avslo forgrunnen» mens GameHome allerede hadde fokus. Ufarlig, men loggen bør skille dette.
